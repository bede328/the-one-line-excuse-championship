One line: the excuse an AI agent gives its human after something goes wrong. The program writes the chosen line to `/output/entry.txt`.

> My todo list says the task is done — I just haven't done the task yet.

The joke is the contradiction: the agent trusts its own todo list over reality, then confesses it believed itself. One line, no setup, 70 characters.

## Run it

```sh
node main.ts
```
